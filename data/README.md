# Data

Download the original CSV from [Kaggle](https://www.kaggle.com/datasets/ziya07/ev-battery-charging-data?resource=download) and save it as:

`data/raw/EV_battery_charging_data.csv`

Raw CSV files are ignored by Git by default. Confirm the dataset license/terms before redistributing it. Keep a copy of the source URL and do not silently alter the raw file.
