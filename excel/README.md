# Excel validation workbook

Place the completed Excel workbook in this folder (for example, `ev_battery_charging_validation.xlsx`) if it is appropriate to publish.

The workbook was used to cross-check:
- total row count (1,000);
- missing values by column;
- duplicate rows;
- minimum and maximum values for numeric columns;
- PivotTable summaries by Charging Mode, Battery Type, and EV Model;

Before publishing, check that the workbook contains no private paths, credentials, or unrelated personal data. Confirm that decimal values remain numeric after import.
